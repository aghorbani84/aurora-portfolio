# Brief A — Loopdesk 60-Second SaaS Product Video: Final Script

> **Sample project — fictional brand Loopdesk, created to demonstrate AURORA's production process**

- **Client (fictional):** Loopdesk — fictional project-management SaaS for remote teams of 5–50 people. Not a real company.
- **Goal:** One action — free 14-day trial signup.
- **Single message:** "Your team's work, in one calm place — no more chasing updates across five apps."
- **Tone:** Calm, competent, plain English. No shouting, no "revolutionary", no jargon.
- **Format:** 60 s, 16:9, 1080p master (plus 45 s 9:16 cutdown and 15 s teaser — see `storyboard.md`).
- **Voiceover pace:** ~150 words per minute. **Total voiceover: 149 words** (limit ≤ 155). At 150 wpm, 149 words = **59.6 seconds** — inside the 58–62 s window.
- **Word-count method:** Voiceover words only, counted word-by-word per segment below (on-screen text is listed separately and is not counted in the 149). Count verified by script (see `qc-checklist.md`).
- **Honesty rule:** No performance statistic, no client quote, no testimonial anywhere in this script. Every claim is a description of the fictional product's stated features or a positioning line, not a measured result. If a real-client version is ever produced, any number in it must come from that client's verified analytics and be cited in the production notes.

## Changes vs the brief's draft script table (and why)

The brief's draft table is the base; this final script polishes it to a speakable 149 words. Every change is a wording/timing change only — no new claim, no new number, no new feature:

1. **0:00–0:05 — unchanged.** The draft's 12-word hook already lands at exactly the right pace for 5 seconds.
2. **0:05–0:15 — extended** ("so nothing hides in a chat thread or inbox anymore"). The draft line alone is 15 words for 10 seconds (~90 wpm — too slow, dead air). The added clause keeps the same idea (one place, nothing hidden) and brings the pace to 150 wpm.
3. **0:15–0:30 — extended** ("so the answer stays with the task"; "quiet, polite reminder, not five pings from five different places"). The draft's three short sentences total 15 words for 15 seconds (~60 wpm). The additions spell out *why* each feature matters, in the same plain register, with no new feature invented.
4. **0:30–0:45 — extended** ("On the left, the old way… On the right, one shared board. Everyone sees the same work, the same priorities, and the same next step."). The draft's single positioning line ("Teams using one shared board stop chasing updates — and start finishing work") is 12 words for 15 seconds. The final version narrates the split-screen the viewer is actually seeing, then keeps the draft's idea as the closing beat ("No chasing. Just finishing work."). **The positioning line is still a positioning line, not a measured result** — no percentage, no "teams finish X% faster", no study cited, because no real Loopdesk user data exists.
5. **0:45–0:55 — extended** ("Set up your first board in minutes, invite your team, and cancel in one click today"). The draft's three sentences are 13 words for 10 seconds. The addition describes only the trial setup the viewer is being invited to do; "in minutes" is a setup description for the fictional product, not a measured onboarding statistic, and "cancel in one click" is the draft's own line, kept verbatim.
6. **0:55–1:00 — added short voiceover** ("Loopdesk. Your team's work, in one calm place. Start your free trial today."). The draft has on-screen text only here. A spoken tagline + CTA closes the video for audio-only listeners (e.g. Shorts scrollers with sound on but eyes elsewhere) and repeats the single message word-for-word.

## On-screen text rules (applied throughout)

- On-screen text never contradicts the voiceover; it either echoes the key phrase or labels what is on screen.
- Maximum one idea per on-screen card; minimum 28 pt equivalent at 1080p so captions stay legible on mobile.
- Brand name, URL and CTA are identical everywhere: **Loopdesk**, **loopdesk.example**, **Start your free trial**.
- "Free 14-day trial. No card required." appears verbatim in the 0:45–0:55 on-screen text, in the thumbnail, and (at edit stage) in the .srt — the same wording in all three places.

## Pronunciation / delivery notes for the voice artist

- "Loopdesk" — LOOP-desk, two even beats, same pronunciation in every segment.
- "loopdesk.example" (final card, on-screen only — not spoken) — the URL is shown, not read aloud, to avoid a clumsy spoken ".example".
- Numbers are spoken as words in the 0:45–0:55 line ("fourteen days") for a calm, human read; the on-screen card shows the numeral ("14-day") for scannability. Both refer to the same 14-day trial.
- "Five apps. Forty notifications." — short pauses after each sentence; let the badges pile up on screen before the question lands.
- No emphasis on any superlative — there are none in the script by design.
